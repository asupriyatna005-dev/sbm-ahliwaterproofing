# SBM Waterproofing Specialist

Starter website SBM 2 untuk GitHub Pages.

## File
- `index.html` — struktur homepage
- `style.css` — tampilan desktop dan mobile
- `script.js` — navigasi mobile dan tahun footer
- `assets/bali-hero.svg` — ilustrasi latar bernuansa Bali (visual sementara)

## Upload ke GitHub
1. Buat repository baru, misalnya `sbm-ahliwaterproofing`.
2. Upload seluruh isi folder ini ke root repository (jangan upload folder ZIP-nya).
3. Buka Settings → Pages.
4. Pada Build and deployment pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu alamat GitHub Pages muncul.

## Sebelum publikasi
- Ganti ilustrasi dan placeholder proyek dengan foto pekerjaan asli SBM.
- Konfirmasi nomor WhatsApp, alamat kantor cabang Bali, email, dan logo resmi.
- Verifikasi klaim pengalaman/garansi sebelum dipublikasikan.
- Setelah GitHub Pages stabil, baru hubungkan domain `sbm-ahliwaterproofing.com`.
